DOCORA HELP

Help centre

A compact guide to editing PDFs with Docora.

Open a PDF

Use the drop area on the home page or open the editor and choose a PDF. The document appears in the workspace with page thumbnails on the left and properties on the right.

Move around the page

  • Mouse wheel: scroll vertically.
  • Shift + wheel: scroll horizontally.
  • Ctrl + wheel: zoom around the pointer.
  • Space + drag, middle-mouse drag or the hand tool: pan freely.

Edit and add content

Use Edit PDF to detect existing text, or choose Text, Image, Sign, Draw, Highlight, Shape, Date or Check. Double-click a text element to type directly.

Select multiple elements

Drag a selection box across the page, use Shift + click, or press Ctrl+A. The Properties panel then provides alignment, distribution, grouping, duplication and deletion tools.

Keyboard shortcuts

  • Ctrl+C / X / V: copy, cut and paste.
  • Ctrl+D: duplicate.
  • Delete: remove selected unlocked elements.
  • Ctrl+G / Shift+Ctrl+G: group and ungroup.
  • Ctrl+Z / Ctrl+Y: undo and redo.

Save work

Download PDF creates the final document. Save project creates an editable .docora file. The last session is also autosaved locally when the browser supports it.
