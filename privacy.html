DOCORA PRIVACY

Privacy

How Docora handles documents and browser data.

Document processing

Docora is designed so that PDF document processing happens in your browser. The PDF you open is not intentionally uploaded to a Docora application server for editing or export.

Local autosave

When autosave is available, the current PDF and project state are stored in your browser using local device storage. This information remains on that browser profile until it is cleared, replaced or removed by the user.

Third-party resources

The current build loads PDF processing libraries from third-party content delivery networks. Those providers may receive standard connection information such as an IP address and browser metadata when their files are requested. Docora does not send your PDF file to those providers as part of the editing workflow.

Files you download

Finished PDFs and editable .docora project files are created in your browser and downloaded through the normal browser download system.

Analytics and cookies

This package does not include analytics, advertising trackers or marketing cookies. A future deployment should update this notice before adding any such services.

This page is a practical product privacy notice, not legal advice. Review it before launch if the service, hosting or analytics setup changes.
