# Deployment checklist

## Domain and SEO

- [x] Final domain configured: `https://docora.uk`.
- [x] Canonical URLs, Open Graph, structured data, sitemap, robots and `CNAME` updated.
- [ ] Add `docora.uk` as the custom domain on the hosting platform.
- [ ] Confirm HTTPS works before public launch.
- [ ] Open `/robots.txt` and `/sitemap.xml` from the live domain.
- [ ] Add the property to Google Search Console and submit the sitemap.
- [ ] Test the social preview using `assets/og-image.png`.

## Functional tests

- [ ] Open a one-page PDF.
- [ ] Open a 50+ page PDF and confirm thumbnails load as they enter the viewport.
- [ ] Add, move, resize, copy, paste, group and lock elements.
- [ ] Drag-select several elements and test alignment/distribution.
- [ ] Test right-click actions and keyboard shortcuts.
- [ ] Edit detected text and export.
- [ ] Save and reopen a `.docora` project.
- [ ] Refresh and recover the autosaved session.
- [ ] Test page reordering and multi-page actions.
- [ ] Verify export with Polish characters.

## Devices

- [ ] Desktop: 1920×1080 and 1366×768.
- [ ] Laptop: 1440×900.
- [ ] Tablet portrait and landscape.
- [ ] iPhone/Android portrait.
- [ ] Touch panning and pinch zoom.

## Legal and privacy

- [ ] Review Privacy and Terms for the final deployment.
- [ ] Update the notice before adding analytics, advertising or server uploads.
- [ ] Do not advertise every PDF as fully editable without the stated limitations.
